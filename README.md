# segen

Static website for SEGEN Healthcare Recruitment.

## Develop

Serve over HTTP so nav/footer partials can load:

```bash
npx serve
```

Compile CSS after HTML class changes:

```bash
npm install
npm run build:css
```

Watch CSS:

```bash
npm run watch:css
```

Place Brandon Grotesque at `assets/fonts/brandon-grotesque-regular.ttf` (already in this repo). Use approved logos in `assets/images/`.
